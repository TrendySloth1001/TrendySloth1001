### Selected work

**[Agent Worker](https://github.com/TrendySloth1001/Agent-worker)**: a personal AI assistant. A Flutter Android app on an Express and Postgres backend that routes each turn across Ollama, OpenAI and OpenRouter models and grounds answers in your files, notes, the web, GitHub, Notion and Drive. Hybrid search (pgvector plus keyword, fused and reranked), long-term memory between chats, and video answers that cite timestamps.<br>
<sub>Flutter · Express · Prisma · PostgreSQL · pgvector · Ollama · OpenRouter</sub>

**[shopxy](https://github.com/TrendySloth1001/shopxy)**: three surfaces over one backend, sketched in the header above. A merchant app for inventory, invoices, parties and vendors, a customer app for invitations and per-shop ledgers, and one Express and Prisma API on Postgres. The same JWT shape works across both apps, so one account works in either. The parts worth the trouble were account linking between merchants and customers, the POS payment flows, and keeping the accounting auditable.<br>
<sub>Flutter · Express · Prisma · PostgreSQL · Redis · MinIO · Docker</sub>

**[Keepit](https://github.com/TrendySloth1001/keepit)**: an end-to-end encrypted vault for passwords, notes, keys and files. The phone holds every key; the server only ever sees ciphertext.<br>
<sub>Flutter · Express · Prisma · Argon2id · AES-256-GCM</sub>

**[wordseed](https://github.com/TrendySloth1001/wordseed)** ([live](https://wordseed-five.vercel.app)): type a word, get sentences. An n-gram model on a suffix array and a small LSTM, both written from scratch, with every sentence explained mathematically.<br>
<sub>Next.js · TypeScript · Python · PyTorch</sub>
