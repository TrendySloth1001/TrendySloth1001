shopxy 2026

Three surfaces over one backend. A merchant app for inventory, invoices, parties and vendors; a customer app showing invitations and per-shop invoice ledgers; and one Express and Prisma API on Postgres. Both apps share the same JWT shape, so a single account works in either. The hard parts were the account-linking model between merchants and customers, the POS payment flows, and keeping the accounting auditable.

Flutter · Express · Prisma · PostgreSQL · Redis · MinIO · Docker Code

Keepit 2026

An end-to-end encrypted vault for passwords, notes, keys and files. The Android client holds every key and encrypts locally; the server only ever stores ciphertext. Argon2id and HKDF for key derivation, AES-256-GCM for storage, resumable multipart uploads for large files.

Flutter · Express · Prisma · Next.js Code

wordseed 2026

Type a word, get as many sentences as you want. Two language models written from scratch, an n-gram model on a suffix array and a small LSTM, grow sentences around the word, then rank, filter and explain each one mathematically.

Next.js · TypeScript · Python · PyTorch Live Code

MrArgue 2026

Two local LLMs debate opposite sides of any topic while a third judges each turn on claim quality and how directly it answers the other side. Responses stream over SSE, and retrieval adds factual context to each argument.

NestJS · Flutter · Ollama · RAG Code
